# Analyse des ventes Superstore (2014-2017)

Analyse exploratoire d'un jeu de données de ~10 000 ventes d'un magasin de détail américain, réalisée avec Excel.

## Outils
Excel — nettoyage des données, tableaux croisés dynamiques, graphiques

## Questions analysées
1. Quelles sont les sous-catégories les plus rentables ?
2. Quelles régions vendent le plus et comment les ventes évoluent-elles par année ?
3. Y a-t-il une saisonnalité dans les ventes ?

## Résultats
- Les **copieurs** sont la sous-catégorie la plus rentable.
- La région **West** génère le plus de ventes ; **2017** est la meilleure année.
- Les ventes culminent en **novembre-décembre** (fêtes) et en **septembre** (rentrée), avec un creux en février (~352 000 $ vs ~59 800 $).
